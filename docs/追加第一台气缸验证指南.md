# 追加第一台真实气缸 —— 验证指南

当前状态：D2 切割 / D3 盘刀 / D8 旋转 = **真实**，其余全仿真。
已完整跑通一次自动流程。

现在要再带一台气缸进来。**关键：不要直接跳进自动流程验证。**
先用手动模式单点验证，确认"阀出得去、传感器读得回"之后，再进自动流程。

---

## 一、先选哪台气缸

建议顺序：**G3（索引 11）→ G2（10）→ G1（9）→ G9（17）**

理由是按自动流程出现的先后：

| 气缸 | 索引 | 自动流程步号 | 互锁复杂度 |
|---|---|---|---|
| **G3 侧推** | **11** | **30 Push**（最早） | **低**：无特殊 CASE 条件 |
| G2 侧挡 | 10 | 40 Clearance | 低 |
| G1 下压 | 9 | 60 PressDown | 中：要求 D8 不忙、G9 抬起、D2 在起点 |
| G9 盘刀升降 | 17 | 70 KnifeDown | 高：要求下压到位、旋转停、定长升、流利条降、侧挡降 |

**先加 G3**：它出现最早（第 30 步），前面等待最短，出错时最容易定位。
下面以 **G3 / 索引 11** 为例，换其它气缸只需把索引和物理点对应改掉。

## 二、阶段 0：手动单点验证（推荐先做这步）

### 为什么手动优先

`FB_Interlocks` 第 37 行：

```st
IF xMotion AND NOT xManualMode THEN
```

**手动模式（`xManualMode = TRUE`）会跳过全部机构互锁。** 所以手动测试是
纯设备级验证：只验"阀 + 传感器 + 状态机"这条最小链路，不受 D2/D8/G9 状态干扰。

这是最安全的起点。手动过了，自动基本就没问题了。

### 操作步骤

**第 1 步：先摆好初始姿态（重要）**

接管前，传感器必须已有信号。否则 `FB_RealCylinder` 接管瞬间姿态未知，
3 秒后报 `3004`，整机直接 Fault。

```
按 G3 退回到位按钮 → xDiG3Retract := TRUE
```

> 为什么必须这一步：`xPositionKnown` 是 `xReady` 的前提。
> 姿态未确立 → `xReady = FALSE` → 不接受任何命令。

**第 2 步：置接管位**

```
GVL_RealDevice.stSettings.axRealDevice[11] := TRUE
```

**注意**：必须在**停止态**（`eState = Stopped`）改这个开关。
`FB_Machine` 第 111 行检测到 `wRealMask` 变化会强制回 `Stopped` 并清初始化。
所以改完要重新初始化。

**第 3 步：进手动模式**

```
GVL_Simulation.stPanelInputs.xAutoMode := FALSE
```

整机自动从 `Stopped` 进 `Manual`（`FB_Machine` 第 150 行：手动不要求初始化）。

确认 `GVL_Interface.stStatus.eState = Manual`。

**第 4 步：下发出位命令**

```
GVL_Interface.aManual[11].lrTarget := 1.0     ← 1.0 = 伸出
GVL_Interface.aManual[11].xMove    := TRUE    ← 脉冲，按住再松开
```

> `xMove` 是**上升沿锁存**，置一次 TRUE 再置 FALSE 即可，请求会保持到本次完成。

**第 5 步：观察**

| 变量 | 预期 |
|---|---|
| `GVL_IO_Physical.xDoG3Valve` | 变 **TRUE**（阀得电） |
| `GVL_Interface.aDeviceStatus[11].xBusy` | TRUE（正在动作） |
| `GVL_Interface.aDeviceStatus[11].udiAcceptedID` | 非 0 |

**第 6 步：模拟到位**

```
xDiG3Retract := FALSE     ← 松开"退回"
xDiG3Extend  := TRUE      ← 按下"伸出"
```

**两个必须同时切换。** 只按 extend 不松 retract → 报 `3003`（两端同时有信号）。

**第 7 步：确认完成**

| 变量 | 预期 |
|---|---|
| `aDeviceStatus[11].lrPosition` | 变 **1.0** |
| `aDeviceStatus[11].xBusy` | 变 **FALSE** |
| `aDeviceStatus[11].udiCompletedID` | = 刚才的 `udiAcceptedID` |
| `aDeviceStatus[11].xError` | **FALSE** |

到这里手动单点就通了。

### 再用反方向验一次

```
lrTarget := 0.0
xMove 脉冲
xDiG3Extend := FALSE     ← 同时松
xDiG3Retract := TRUE     ← 同时按
```

确认能回 0.0。**只有能双向动，才算这台气缸真的通了。**

## 三、阶段 1：自动流程验证

手动通过后，再回到自动。

**第 1 步：回到停止态**

```
xAutoMode := FALSE
xStop     := TRUE 脉冲     ← 强制回 Stopped
```

**2 步：确认接管位仍是 TRUE**

```
axRealDevice[11] = TRUE
```

**第 3 步：摆好初始姿态**

`FB_Initialize` 第 20 步要求 **G3 到 0.0（退回）**：

```
xDiG3Retract := TRUE
xDiG3Extend  := FALSE
```

**第 4 步：初始化**

```
xAutoMode     := TRUE
xInitialize   := TRUE 脉冲
```

等 `eState` → `Ready`，`uiInitializeStep` 走完 `10 → 20 → 25 → 30 → 40 → 1000`。

> 第 20 步会同时等 G2、G3、D5、G4、G7。G2/G4/G7 是仿真会自动过，
> **只有 G3 需要你确认在 0.0**。

**第 5 步：启动自动**

```
xStart := TRUE 脉冲
```

**第 6 步：跟着 eAutoStep 走**

到 **30（Push）** 时，就是 G3 的验证点：

```
xDiG3Retract := FALSE
xDiG3Extend  := TRUE
```

到位后流程自动进 40（Clearance）。

> **注意**：第 40 步 Clearance 会要求 G3 **松开回到 0.0**。
> 所以到 40 步时你要反过来：
> ```
> xDiG3Extend  := FALSE
> xDiG3Retract := TRUE
> ```
> 这是容易卡住的地方——在 30 步按了 extend，到 40 步忘了松。

**第 7 步：继续到 120 完成**

后面 G9 是仿真会自动过，D2/D3/D8 是真实（你已经验过）。
走完 `10 → 120` 且 `eState` 回 `Ready` 即成功。

## 五、三个最容易踩的坑

### 坑 1：先置接管位、后按传感器

接管瞬间两端无信号 → 3 秒后 `3004` → 整机 Fault。

**顺序必须是：先按传感器 → 再置 axRealDevice。**

### 坑 2：在运行中改 axRealDevice

`FB_Machine` 第 111 行：`wRealMask` 一变就强制 `Stopped` + 清初始化。

所以**每次改接管位都要重新初始化**。不要在自动跑一半时改。

### 坑 3：第 40 步忘了松 G3

第 30 步 Push 要求 G3 = 1.0，第 40 步 Clearance 要求 G3 = 0.0。

如果 40 步卡住，先看 `aDeviceStatus[11].lrPosition` 是不是还在 1.0。

## 六、错误码

| 码 | 含义 | 修法 |
|---|---|---|
| `3003` | 两端同时有信号 | 松开一个按钮，同步切换 |
| `3004` | 3 秒无任何信号 | 按下代表当前位置的按钮 |
| `3005` | 10 秒未到位 | 检查按钮 / 映射绑定 |
| `2001` | 目标超出 0/1 范围 | `lrTarget` 只能是 0.0 或 1.0 |
| `10011` | 整机级设备 11 故障 | 对应上面 300x |
| `4620` | 初始化卡第 20 步 | G3 未到 0.0 |
| `4830` | 自动卡第 30 步 | G3 未到 1.0 |

G3 跑通后，按同样方法加 G2（索引 10）：

1. 手动单点双向验证
2. 自动流程验证（第 40 步 Clearance 会用到 G2 下降）
