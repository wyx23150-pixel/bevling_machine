# G1 单气缸验证 —— 监视变量清单

在 InoProShop 里新建监视表，按需添加。分四组，从上到下依次看。

## 第 1 组：整机状态（先看这组）

```
GVL_Interface.stStatus.eState
GVL_Interface.stStatus.eMode
GVL_Interface.stStatus.eAutoStep
GVL_Interface.stStatus.udiAlarm
GVL_Interface.stStatus.uiBlockedDevice
GVL_Interface.stStatus.uiInitializeStep
GVL_Interface.stStatus.xReady
GVL_Interface.stStatus.xInitialized
```

**判读**：
- `eState` 正常流转：`Stopped → Initializing → Ready → Automatic → Ready`
- `eAutoStep` 卡住 = 当前步设备没到位
- `uiBlockedDevice` 非 0 = 该设备被互锁挡（9 就是 G1 被挡）
- `uiInitializeStep` 卡在 10 = G1 没到抬起位

## 第 2 组：操作输入（要改的）

```
GVL_Simulation.stPanelInputs.xAutoMode
GVL_Simulation.stPanelInputs.xInitialize
GVL_Simulation.stPanelInputs.xStart
GVL_Simulation.stPanelInputs.xStop
GVL_Simulation.stPanelInputs.xResetAlarm
```

**注意**：`xSimulation = TRUE` 时，面板信号从这里读，外面板按钮无效。
每个按钮都要**按住再松开**才能形成上升沿，一直保持 TRUE 只算一次。

## 第 3 组：G1 物理点（你的按钮）

```
GVL_IO_Physical.xDiG1Retract
GVL_IO_Physical.xDiG1Extend
GVL_IO_Physical.xDoG1Valve
```

**判读**：
- 按物理按钮时，对应的 `xDi*` 要跟着变。**不变 = 映射没绑对**
- `xDoG1Valve` 在下压期间应该是 TRUE

## 第 4 组：G1 设备状态

```
GVL_Interface.aDeviceStatus[9].lrPosition
GVL_Interface.aDeviceStatus[9].xReady
GVL_Interface.aDeviceStatus[9].xBusy
GVL_Interface.aDeviceStatus[9].xError
GVL_Interface.aDeviceStatus[9].udiErrorID
GVL_Interface.aDeviceStatus[9].udiCompletedID
GVL_Interface.aDeviceStatus[9].xHomed
```

**判读**：
- `lrPosition`：0.0 = 抬起，1.0 = 下压。随按钮跳变
- `xReady`：FALSE 且 `udiErrorID = 3004` → 传感器没信号
- `xHomed`：这里表示"姿态已确立"，不是机械回零。需要 TRUE 才能收到命令

## 第 5 组：接管开关（确认配置）

```
GVL_RealDevice.stSettings.axRealDevice[9]
GVL_RealDevice.stSettings.axRealDevice[10]
GVL_RealDevice.stSettings.axRealDevice[11]
GVL_RealDevice.stSettings.axRealDevice[17]
GVL_Parameters.xSimulation
GVL_Parameters.xContinuous
```

**第一轮建议**：只 `axRealDevice[9] = TRUE`，其余气缸保持 FALSE。

## 第 6 组：其它气缸（第一轮应为仿真）

```
GVL_Interface.aDeviceStatus[10].lrPosition
GVL_Interface.aDeviceStatus[11].lrPosition
GVL_Interface.aDeviceStatus[17].lrPosition
GVL_Interface.aDeviceStatus[3].xActive
GVL_Interface.aDeviceStatus[2].lrPosition
```

仿真设备的位置会自己变，不用操作。

## 最快排查路径

卡住时按这个顺序查：

```
1. eState 是什么？
   Fault      → 看 udiAlarm，查错误码表
   Stopped    → 初始化没做或做失败了
   Automatic  → 看 eAutoStep

2. eAutoStep 卡在几？
   60  → 就差 G1：查 xDiG1Extend / xDoG1Valve / aDeviceStatus[9]
   其它 → 那一步的设备有问题

3. aDeviceStatus[9].xError 是 TRUE？
   看 udiErrorID：3003 两端同时 / 3004 无信号 / 3005 超时

4. uiBlockedDevice 非 0？
   是 9  → 互锁挡住，查前置条件（D8 不忙、G9 抬起、D2 在起点）
```

## 错误码速查

| 码 | 含义 | 修法 |
|---|---|---|
| 3003 | 两端同时有信号 | 松开一个按钮 |
| 3004 | 3 秒无任何信号 | 按下当前位置对应按钮 |
| 3005 | 10 秒未到位 | 检查按钮/映射 |
| 10009 | 设备 9 故障（整机级） | 修上面 300x |
| 4610 | 初始化卡第 10 步 | G1 未到抬起位 |
| 4660 | 自动卡第 60 步 | G1 未到下压位 |
